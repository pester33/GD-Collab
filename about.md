# GD Collab

Build a level **together, live**.

1. Open your level in the editor, pause, and press **Collab** -> **Host a room**. You get a room code like `K7Q2P`.
2. Friends go to **My Levels**, press the green **Collab** button on the left, type the code and **Join**. A new level opens with a copy of yours.
3. You see each other's cursors and names, and anything someone places flashes in their color.
3. Everyone builds at the same time: placed, moved, edited and deleted objects sync about once a second.

The status line in the top-left of the editor shows the room, who's online and the last change.

**Good to know**
- Everyone saves their own copy of the level.
- Syncing pauses while you playtest.
- If two people edit the same object at the same time, the newest change wins.
- Level settings (song, colors, start options) aren't synced yet.
